# 資料與描述統計

## 學習目標

能解釋 平均數、中位數、變異數、標準差、分位數、樣本、特徵與標籤，並將概念用於 AI 資料或模型結果的判讀。

## 對應教材

DLI：01 MNIST、02 ASL。完整章節連結見 [對照表](../dli-mapping.md)。

## 建議教學順序

1. 以實際資料或簡單模擬提出問題。
2. 用圖表呈現直覺，再說明 平均數、中位數、變異數、標準差、分位數、樣本、特徵與標籤。
3. 手算小型例子，接著以 Python 驗證。
4. 連結 DLI 操作，討論結論與限制。

## 實驗任務

統計各類別張數與比例；畫出像素直方圖，找出離群值與類別不平衡。

## 思考題

若平均像素相同，兩張影像是否相同？請用分布解釋。

## 繳交內容

資料來源與切分方式、實驗條件、結果圖表、200–400 字解讀，以及至少一項限制。使用 AI 協助時，附使用方式及自行驗證紀錄。

## 完成標準

能重現結果、正確說明指標或統計量，並辨識結果不足以支持的主張。對小樣本例子避免過度推論。
