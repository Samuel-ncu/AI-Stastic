# 課程大綱

## 對象與先備能力

商管及跨領域學生；具 Python 基礎，能使用變數、函式與表格資料。先複習 NumPy 陣列、pandas 與 Matplotlib。矩陣運算、導數及梯度另以短篇補充，作為神經網路所需數學工具。

## 第一階段：必修 14 小時

| 單元 | 時數 |
|---|---:|
| 1. 資料與描述統計 | 2 |
| 2. 機率與分類 | 2 |
| 3. 抽樣與資料切分 | 2 |
| 4. 尺度與標準化 | 2 |
| 5. 從統計模型到神經網路 | 2 |
| 6. 過擬合與泛化 | 2 |
| 7. 分類模型評估 | 2 |

每單元包含概念說明、示範及結果解讀。正式 DLI 模型訓練時間另計；可拆成七次課程穿插於 DLI 教學。

## 第二階段：進階 6 小時

不確定性與模型比較、實驗設計、文字統計各 2 小時；視學生程度延伸。

## 完課能力

1. 描述資料分布與可能偏誤。
2. 正確切分資料並防止洩漏。
3. 解釋損失函數與訓練曲線。
4. 依決策成本挑選評估指標。
5. 用公平實驗及不確定性分析比較模型。

## 作業

以三個核心實驗形成期末報告，附程式、實驗條件、結果表、圖、限制及 AI 使用說明。評分見教師規劃。
