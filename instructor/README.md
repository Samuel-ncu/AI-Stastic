# 教師教學規劃

## 教學原則

先讓學生猜測結果，再用圖表及程式驗證。以 MNIST 與 ASL 貫穿概念，減少重複熟悉新資料的負擔。每個實驗都必須有簡單基準。

## 建議評分規準

| 項目 | 配分 |
|---|---:|
| 問題與統計概念 | 20 |
| 資料切分與實驗公平性 | 25 |
| 程式、結果及重現紀錄 | 20 |
| 解讀、決策意義及限制 | 25 |
| 來源、AI 使用與驗證說明 | 10 |

## 常見誤解

- softmax 分數不保證已校準，需用資料檢查其可靠性。
- 更多增強影像不等於更多獨立觀測。
- 相關不等於因果；觀察到分數差也不等於改動造成普遍提升。
- 固定種子有助重現，但單一種子不足以呈現訓練變異。
- 信賴區間須說明抽樣單位與方法，不能直接解讀為固定參數有 95% 機率落入已算出的區間。
