# 三個核心實驗

## 實驗一：準確率很高，模型為何沒有用？

建立 990 筆負類與 10 筆正類的模擬資料。先評估永遠猜負類的基準，再比較能識別部分正類的模型。計算混淆矩陣、Accuracy、Precision、Recall 及 F1；分母為零時須明確記錄處理方式。

提交：各指標、錯誤成本表、閾值選擇理由。說明 99% Accuracy 為何不足以證明模型有用。閾值以驗證集選擇，最後才評估測試集。

## 實驗二：進步 1% 是否可信？

固定訓練／驗證／測試切分，在相同測試樣本比較基準模型與改良模型。先以多個訓練種子記錄變異，再選定模型做測試樣本的配對 Bootstrap。

每次重抽相同樣本索引供兩模型共同使用，記錄準確率差；重複例如 2,000 次，計算 percentile 95% 區間。若資料有拍攝者或群組相依，改以群組為重抽單位。此區間描述固定模型的測試抽樣不確定性，不包含重新訓練的所有不確定性。

提交：每個種子的結果、平均與標準差、差值區間及效果量。避免只憑區間或單次分數宣稱普遍優越。

## 實驗三：資料增強一定有效嗎？

比較無增強、合理增強、過強增強。保持切分、模型、訓練預算及種子集合一致。增強只用於訓練集；同一原圖的衍生影像不可跨集合。

先檢查變換後的圖與標籤是否仍合理，尤其手語的翻轉及旋轉不能直接假定保留語意。

提交：增強範例、學習曲線、每類指標及錯誤分析。以驗證集選設定，再對封存測試集做最後評估。

## 共同報告格式

研究問題、資料來源、切分方式、假設、控制變因、方法、結果、解讀、限制、重現步驟、AI 協助及驗證紀錄。
